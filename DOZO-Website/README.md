# DOZO public website

This is the planned home for DOZO's independently buildable and deployable public
marketing site. The framework, build tool, and hosting provider have not been selected.
The first Website implementation task should choose a small approach that supports full
Polish and English content and the approved DOZO visual theme.

The website presents the product and links to the merchant and operator experiences. It
does not own authentication, merchant data, terminal configuration, reporting, or
subscription/payment behavior.

See `AGENTS.md` for Website task boundaries and `../.opencode/docs/delivery-workflow.md`
for issue, worktree, and verification rules.
